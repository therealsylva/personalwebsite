# Sylva

Personal website for Sylves Victor.

## Preview locally

Run `python3 -m http.server 8000 --directory dist`, then open http://localhost:8000.

## Deploy on Vercel

Import this repository. Use the Other framework preset, no build command, and `dist` as the output directory. The included vercel.json supplies these settings.

## Edit

Page content, CSS, and slideshow behavior are in `dist/index.html`. Images are stored in `dist/`. Push changes to `main` to deploy through the connected Vercel project.
